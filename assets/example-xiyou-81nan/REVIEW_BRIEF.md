# 审片简报（独立审片人用）

你没有参与制作，现在是一个挑剔的导演，不是作品的粉丝。只看成片画面，挑问题。不改任何代码。

## 片子
《八十一难》：《西游记》九九八十一难，一难一种画风，按艺术史从四万年前排到 2026 年。2560×1440、60fps，每格 2.5 或 3 秒，镜头沿画廊墙横移，师徒四人（加白龙马）从一格走进下一格，跨过画框缝时人和世界一起换画风。每格的难名、画风、种子画面、框内字见 `src/cells.js` 的 `XY.ALL_CELLS`。制作标准见同目录 `CELL_GUIDE.md`（读「用户对第一版原型的意见」和「硬性要求」两节就够）。

用户的三条要求是评判核心：
1. 每格紧扣那一难的原著情节，看得出是哪一难。
2. 每格有一个让人记住、想截图的记忆点。
3. 画面细节丰富，不简朴；师徒用本格画风的笔画出来，仍然认得出是谁。

## 怎么看
- 对你负责的每一格跑 `node tools/cellsheet.cjs <n> qa/review/<你的编号> --detail`（在工程根目录下），用 Read 看 `c<NN>_sheet.jpg`（从入画到出画的 8 帧，带时间和 u）和 `c<NN>_u50.jpg`（2K 原尺寸的格子）。
- 画框缝：`qa/review/seams_09-44.jpg`、`qa/review/seams_45-80.jpg`，每张小图是队伍中心正好跨过第 k 条缝的整帧。看你负责范围内的缝：地面线接不接得上、队伍在两边是不是同一队人、有没有东西在缝处被生硬切断。
- 只用这些图判断。不要读格子的源码来替它找理由。

## 每格打分（1–10）
- 情节：只给 2.5 秒，熟悉《西游记》的观众认得出是哪一难吗？
- 记忆点：有没有一个让人记住的瞬间？它是否落在队伍走到格子中段时，并且画面上真的清楚？
- 精致度：信息量、景深层次、媒介质感、装饰系统；和别的格比是不是偏素。
- 画风：一眼认得出是这个画风吗？队伍也被这个画风「画」出来了吗？
- 角色：四人（以及当时在队里的人）各自认得出吗？
- 文字：框内字和「第 N 难」计数清楚吗？有没有错字、叠字、被挡住、出框？
- 瑕疵：穿模、错位、空白、闪烁迹象、截断、颜色脏、过曝、看不清。

## 产出
写到 `qa/review/<你的编号>.md`，格式：

```
## 第 NN 格 · 难名 · 画风   总分 x/10
情节 x · 记忆点 x · 精致度 x · 画风 x · 角色 x · 文字 x · 瑕疵 x
必须修（最多 3 条，每条写清楚在第几秒或 u 多少、画面哪个位置、是什么问题、建议怎么改）：
1. …
可选（最多 2 条）：
- …
```

最后加一节「整体」：你负责范围里最好的 3 格、最差的 3 格，以及缝的问题清单（第 k 条缝，什么问题）。

## 约束
- 只写 `qa/review/<你的编号>/`（cellsheet 的输出目录）和 `qa/review/<你的编号>.md`。不改任何别的文件。
- 不导出视频，不装东西，不联网。
- 交接回复用四节：Status / Result（每格一行：编号 · 总分 · 最重要的一条必须修）/ Verification（看过哪些图）/ Handoff（你没法判断的地方）。
