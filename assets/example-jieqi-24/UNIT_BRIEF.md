# 第三轮简报：把每格扩成成片用的 8 秒单元

工程根目录 ``。Art Lock 已定稿（用户说「这一轮我相信你的成果」），现在做成片。每个节气在片子里是 8 秒（90 BPM 下 3 小节）。音乐每小节换一个和弦，**三候各占一小节**，画面事件必须踩在音乐上。先读 `ARTLOCK_BRIEF.md` 第二、三节（接口和硬规则照旧）、`ARTLOCK_BRIEF_v2.md`（中国画风要点和禁区）、`artlock/film.js` 文件头（引擎契约）。

## 一、时间结构（硬性）

- 本地时间 `t` 从 0 到 8：候一 `[0, 2.667)`，候二 `[2.667, 5.333)`，候三 `[5.333, 8)`。每候在自己那一小节开头开始，演一个看得见的事件（不小于 80 设计像素），发生在它自己的位置。
- **记忆点那一候**（`JQ.TERMS[n-1].keyHou`）是全格最大的事件，它的「落点」（闪电劈下、鹿角落地、大蚌张开、麻雀变成蛤蜊）必须正好在那一小节的第三拍：`impact = keyHou × 8/3 + 4/3` 秒（候一 1.333、候二 4.0、候三 6.667）。音乐会在这一刻打一下钟加镲片渐强，所以误差不超过 1/30 秒。
- 其余两候是较小的事件，但要能读懂，比如「东风解冻」可以是冰面裂开、风纹吹过；「蛰虫始振」可以是地下的虫动了一下。三候的原文都在 `artlock/terms.js`。
- `t = 0` 是开场状态：画风已经铺满，候一即将发生。下一格会从你的 `focus[0]` 那里长出来盖住上一格，所以开场画面要完整、好看。
- `t` 在 8 到 9 秒之间：保持或延续最后状态（引擎在下一格长出来的过程中还会继续画你的格子，最多到约 8.85 秒）。**删掉 Art Lock 版本里 3.6 到 4 秒淡回开头的逻辑。**
- 娃和牛全程在画面里，可以随三候走动、换姿势。

## 二、注册字段（`tools/unitsheet.cjs` 会检查）

```js
JQ.ART[NN] = {
  key: impact,                       // 记忆点落点时刻（秒），用于缩略图和检查
  keyHou: JQ.TERMS[NN - 1].keyHou,
  focus: [[x1, y1], [x2, y2], [x3, y3]],   // 三候事件的位置（设计坐标）。镜头每候向它轻推，下一格从 focus[0] 长出
  frame: false,                      // 有边框、绫边、挂屏框的画风填 true，镜头就不动，免得裁掉边框
  draw(g, t, Sx) { ... },
};
```

- 镜头：`frame: false` 时引擎会在 8 秒里推近到 1.035 倍，锚点偏向当前候的 `focus`，所以题字和重要内容离画面边缘至少 70 设计像素。
- 框内字：节气名一直在；候的原文在每小节开头换成当前这一候（用本画风的方式出现：刻、印、写、绣），不小于 40 设计像素。

## 三、性能和确定性

- 成片按 2560×1440 导出。`node tools/unitsheet.cjs NN` 报 2560 宽下的平均、p90、最大帧时，要求平均 ≤ 25 ms、p90 ≤ 40 ms。静态的东西放 `JQ.cached`；逐像素处理只在缩小的层上做。
- 确定性照旧（同一 `t` 渲染两次逐像素一致，工具会查）。不用 `Math.random`、`Date`、`performance`。

## 四、流程

1. 在 `qa/units/LOG-<队名>.md` 写每格三行计划：三候各演什么（位置、几秒开始、落点）、哪里用到娃和牛、要修的短板。
2. 改代码（每次 Write 或 Edit 不超过 150 行），`node --check`，然后 `node tools/unitsheet.cjs NN`：出 `qa/units/sNN_sheet.jpg`（8 帧拼图，标了时间和第几候）和 `sNN_key.jpg`（记忆点落点那一帧，1920 宽），报帧时、确定性和契约问题。用 Read 看拼图（每次只读一张图）。
3. 自查：三候是否各有一个看得懂的事件？落点是否正好在 impact？开场画面是否完整？题字是否换候？娃和牛在不在？画风有没有在 8 秒里保持住？挑最差的三处改。**每格最多改两轮。**
4. 日志里记：三候怎么演、impact、帧时、已知短板。

## 五、各格要顺手修的短板（来自前两轮的交接和主代理审图）

- 01 立春（蓝印花布）：娃偏小，可放大到 1.15；冰片和鱼都要更大更清楚。
- 03 惊蛰：圆章里的小鸟太小，放大或减到三枚；金丝格手工感不够。
- 04 春分：界画细节集中在右半，左半也加一点界尺画的东西（院墙、桥栏）；树冠被绫边切掉一点。
- 07 立夏：树冠里的洇色圆斑改成小色点；地面加几片小花草。
- 08 小满：远处农人太小，可减少数量、放大前排。
- 09 芒种：最弱的一格。墨色偏灰，前景叶提高浓度、减纸纹侵蚀；小螳螂群要成规模、看得清。
- 10 夏至：鹿重画得更工笔（脖子到胸的转折、细腿关节）；小蝉可以大一点。
- 12 大暑：萤火再多一点、轨迹更弯更长；大雨要在候三（大雨时行）真正下大。
- 13 立秋：风痕改成两端渐细的整笔；牛改成几笔湿墨的写意牛。
- 14 处暑：树冠是圆团，改成木刻的点叶或夹叶；连枷两人错开相位。
- 16 秋分：蛴螬洞被右边缘切掉，往里收；标注引线不要交叉。
- 第二轮冬队交回的 17 到 21、22 到 24 的短板，见 `qa/art/LOG-winter.md` 和 `qa/art/LOG-autumn.md` 末尾。

## 六、分工（唯一可写）

每队只写自己那 6 格的 `artlock/styles/sNN.js`、自己的 `qa/units/LOG-<队名>.md` 和 `qa/units/` 下自己格子的图。其余一律只读，尤其不要改 `core.js scene*.js figures.js flat.js terms.js film*.js ring.js render.html runtime.js score-jq.js audio-*.js tools/`。缺引擎功能就在本格文件里自己写局部 helper，或在交接里写需求。
