# 第四轮简报：农家一年（把故事轨接进 24 种画风）

工程根目录 ``（不是 git 仓库）。用户看了 v1 成片后的意见：「画面故事感不强。不同节气之间的连接，无论是画面自然切换，还是说主体（农妇、耕牛）的变化都没做好。」用户选定的主体是**农家一家：农妇、娃、耕牛，春天（清明）生一头小牛犊，一年里慢慢长大**。

主代理已经把「故事」做进引擎：人和牛的位置、动作、衣服、农具是**全片时间的函数**，和画风无关。所以换画风时，人物在原地，世界换了画风；过渡也由引擎按下一个节气的现象来做（雨幕、霜、冰、雪……）。你们的任务是**让每种画风用自己的笔法画出这一家人**，并让画面里的田地、农事和故事对上。

先读：`UNIT_BRIEF.md`（第三轮，时间结构和注册字段照旧）、`ARTLOCK_BRIEF_v2.md`（画风要点和禁区），再读引擎新文件：`artlock/story.js`、`artlock/story2.js`（接口）、`artlock/storydata.js`、`artlock/storydata2.js`（每个节气一家人在做什么）、`artlock/figures2.js`（人）、`artlock/figures3.js`（小牛和农具）。故事预览图（中性平涂上画的一家人，每个节气 5 个时刻）：`qa/story/cast_1-8.jpg`、`cast_9-16.jpg`、`cast_17-24.jpg`。

## 一、接口（硬性）

- **删掉画风自己画的娃和牛**（`JQ.kid`、`JQ.ox`、`JQ.kidParts`、`JQ.oxParts` 的调用，以及缓存里画好的人和牛）。
- 每帧调用 `const C = JQ.castFor(Sx, t)`，得到 `C.items`（已按远近排好，从后到前）。每个 item 是 `{ who, kind, parts, y, alpha }`：`who` 是 `woman` `kid` `ox` `calf`；`kind` 是 `actor`（人或牛本身）或农具名；`parts` 是 `[{ role, pts, path }]`，`pts` 是点列，`path` 是 Path2D，都在设计坐标里。`C.state` 里有每个人的 `x y dir pose phase s`，`C.items[i].parts.joints` 里有人的手、头、肩的位置（`hand hand2 head shoulder hip`）。
- 用本画风的笔法逐个画 parts，按 role 上色。最省事的是 `JQ.drawCastFor(g, Sx, t, pen)`（按 pen 平涂加描边）；但**要让人物像是这个画风画出来的**：刻线、针脚、剪纸刀口、墨色晕染、热像亮度、X 光骨架、七巧板（七巧板格可以用 parts 的包围盒拼板块）。参考你们之前怎么画娃和牛，换成画 parts。
- role 清单：`skin hair coat pants apron hat scarf straw cape eye`（人）；`ox oxDark horn eye`（牛）；`calf calfDark horn eye`（小牛）；农具 `prop`（木）`metal`（铁、石）`straw`（草编、麦捆）`red`（红绸、春联、灯笼、碗）`line`（绳、线）。pen 里没写的 role 会回退（`figures.js` 的 `JQ.ROLE_FALLBACK`），但请给这些 role 都配上本画风的颜色。
- `JQ.castFor(Sx, t)` 必须每帧调用，不能缓存人物（他们在动）。不要自己改人物的位置和动作；觉得故事和你的画面冲突，写进交接，由主代理改故事数据。
- 人物要画在背景之后、前景遮挡物（近处芦苇、雨、雾、雪、萤火）之前或之后，按画面合理安排。人物走过桥面、进出院门、站在田里时要看着合理。
- 远处田里的人物缩小到约 0.7 倍（引擎已经按远近缩放），要保证在本画风里仍看得清，可以给人物加一圈本画风的亮边或暗边。

## 三、标题和过渡（引擎负责，你们只要配合）

- 每个节气 0.15 到 2.25 秒，引擎在天空中部（x 530 到 1390，y 90 到 320）展开一条写着节气名的宣纸题签。这段时间里不要在这块区域安排关键事件。你们画面里自己的题字保留，放在原来的角落。
- 过渡由引擎画：新画风从下一个节气的现象里出现（`artlock/trans.js`）。你们只要保证 t = 0 的开场画面完整，t 在 8 到 9 秒保持最后状态。

## 四、检查和流程

1. 先跑 `node tools/storycheck.cjs`（故事数据的连续性，应该显示通过；你们不改故事数据）。
2. 改代码（每次 Write 或 Edit 不超过 150 行，改文件用 Write/Edit），`node --check`，然后 `node tools/unitsheet.cjs NN` 看 8 帧拼图（`qa/units/sNN_sheet.jpg`），要求 contract ok、deterministic、不报 OVER BUDGET。
3. 自查：一家人是不是用本画风的笔法画的？在每一帧都在吗？农事和地面状态对得上吗？三候事件和人物有没有打架？远处的人看得清吗？每格最多改两轮。
4. 日志写在 `qa/units/LOG-<队名>.md` 末尾（第四轮）。

## 五、唯一可写

每队只写自己那 6 格的 `artlock/styles/sNN.js`、`qa/units/LOG-<队名>.md`、`qa/units/` 下自己格子的图。其余一律只读（尤其 `story*.js storydata*.js figures*.js film*.js trans.js titles.js ring.js core.js scene*.js terms.js tools/`）。
