# 《二十四节气》Art Lock 简报（给四支季节队）

工程根目录：``（不是 git 仓库）。Art Lock 页的目的：用户要在正式制作前，逐张看 24 种画风画同一个村口的样子，锁定或换掉画风。所以每张样图要让懂这个画风的人**一眼认出画风**，同时让人看懂这一节气的**记忆点**。

## 一、片子是什么

《二十四节气》：同一个黄河流域的村口，机位不动，一年 24 个节气，每个节气一种画风（按季节气质配：春清新、夏饱和热、秋金褐、冬冷而少色）。每个节气 8 秒，演三候；Art Lock 阶段每张只做**记忆点那一候**的一个 4 秒小循环，卡片显示其中最能说明问题的一帧（`key`）。

## 二、文件和接口

- 你只写自己负责的 `artlock/styles/sNN.js`（已有占位文件，直接覆盖）。其余文件只读。
- 先读：`artlock/core.js`、`artlock/scene.js`、`artlock/scene2.js`、`artlock/figures.js`、`artlock/flat.js`、`artlock/terms.js`（`JQ.TERMS[NN-1]` 是你这一格的三候、画风、记忆点）。
- 布局底图：`qa/art/s00.jpg`（`flat.js` 的中性渲染）。这就是固定构图。
- 注册方式：

```js
(function () {
  const JQ = window.JQ, S = JQ.SCENE, L = JQ.L;
  JQ.ART[NN] = { key: 2.4, draw(g, t, Sx) { /* ... */ } };
})();
```

- `draw(g, t, Sx)`：`g` 已缩放到设计坐标 1920×1080；`t` 是 0 到 4 秒的小循环时间（4 秒处应能接回 0 秒，做不到就让 3.6 到 4 秒淡回开头状态）；`Sx.scale` 是设备像素与设计像素之比。
- 离屏层用 `JQ.layer(name, Sx, { read })`，静态背景用 `JQ.cached(name, Sx, build)`，贴回用 `JQ.blit(g, L)`。逐像素处理（`getImageData`）只能在缩小的层上做（`{ res: 0.5 }` 或更小）。
- 场景部件：`S.mountains S.ridge S.hills S.field S.furrows[] S.stream S.pond S.pondRim S.bridge S.bridgeArch S.path S.ground S.trunk S.branches[] S.canopy S.clumps[] S.tips S.wall S.wallCap S.gate S.gateRoof S.houseFront S.roof S.roofLines[] S.window S.chimney`，每个都有 `pts`（点列）和 `path`（Path2D）。`JQ.drawBranches(g, maxDepth, widthScale)` 画枝干；`JQ.jitter / JQ.resample / JQ.smoothPath` 可做手绘线。关键坐标在 `JQ.L`（池塘、树、院墙、桥、娃和牛的默认位置、天空带）。
- 角色：`JQ.kidParts(x, y, s, pose)`、`JQ.oxParts(x, y, s, pose)` 返回 `[{ role, pts, path }]`（从后到前），按 role（skin hair coat pants ox oxDark horn eye hat）用本画风的方式画；或者直接 `JQ.kid / JQ.ox` 加自己的 `pen`。姿势：娃 `stand walk run reach sit squat ride`（`phase`、`dir`、`hat`），牛 `stand walk graze lie`。娃的双丫髻和牛角是识别符，不能丢。
- 工具函数：`JQ.hash rng noise fbm lerp smooth ease clamp mix rgba vtext`。

## 三、硬规则

1. **构图不动**：远山、田、老槐树（左）、池塘（中）、石桥和小溪（右中）、院墙和院门（右）、娃和牛（左前）都在约定位置。可以简化、变形成本画风的样子，可以加本画风的边框（内缩不超过 60 设计像素）和装饰，但不能挪走主要元素，不推镜头。
2. **只学画风语言，不搬画风原有的题材和名作构图**。每格的禁区见第五节。画面里的东西只能来自村口、节气、三候和农事。
3. **记忆点要大、要清楚**：关键物件不小于 80 设计像素，事件发生在约定的位置（池塘、树、天空、院墙、田）。
4. **框内字**：节气名（不小于 64 设计像素）加记忆点那一候的原文（不小于 40 设计像素），用本画风自己的书写方式（木刻字、题签、霓虹、HUD、泥金首字母等）。不在画面里写画家名字。
5. **确定性**：不用 `Math.random`、`Date`、`performance`；同一 `t` 渲染两次必须逐像素一致（工具会检查）。
6. **性能**：1920 宽渲染 `key` 帧不超过 400 毫秒；动画帧尽量在 60 毫秒以内。
7. **每次 Write 或 Edit 不超过 150 行**；一个文件可以分几次写。
8. 避开一眼 AI 味：不要渐变背景加正中大标题，不要蓝紫霓虹（热成像这类媒介本身如此的除外），不要给物体乱加脸。

## 四、每格的流程

1. 先在 `qa/art/LOG-<队名>.md` 里写五行计划：画风的三到五个可识别特征（材质、线条、色板、构图逻辑、装饰）、记忆点怎么演、娃和牛怎么画、框内字怎么写、这一格最容易做砸的地方。
2. 写代码，然后在工程根目录跑：`node tools/shot.cjs NN`（出 `qa/art/sNN.jpg`，报毫秒和确定性），再用 Read 看图。动画抽查：`node tools/shot.cjs NN 0.5 1920 qa/art/t` 和 `... 3.5 ...`。
3. 当挑剔的美术指导：这一张能不能让懂行的人一眼说出画风？记忆点看得懂吗？挑最差的三处改。**每格最多改两轮**。
4. 在日志里记：做了什么、key 帧时间、毫秒、已知短板。

工艺参考（只读，学手法不学内容）：上一部片《八十一难》的画风文件在 `../example-xiyou-81nan/src/styles/`，比如 `rimpa.js`（金屏风）、`shinkai.js`（光影）、`ascii.js`（亮度缓冲转字符）、`oracle.js`（刻痕）、`bluewhite.js`（青花晕散）、`puppet.js`（皮影）。

## 五、每格的画风要点和禁区

春队（team-spring）：02 到 06。
- **02 雨水 · 吴冠中式点线**：大片留白和灰白墙面，长而有节奏的黑色墨线（树枝、屋脊、田埂），点点色彩（嫩绿、桃红、鹅黄）像撒上去；雨是细斜线。记忆点：水獭在池岸把鱼一条条摆齐。禁区：不照搬他的江南水乡名作构图（双燕、白墙黑瓦群）。
- **03 惊蛰 · 威廉·莫里斯纹样**：平涂的靛蓝、茜红、黄木樨色和多层绿，藤蔓和叶子的重复纹样铺满边框、树冠、田；有轮廓线。记忆点：一只鹰沿藤蔓纹样绕一圈，出来变成斑鸠（变形过程要看得见）。禁区：不照搬「草莓小偷」等具体名作（画眉衔草莓）。
- **04 春分 · 风格派**：场景简化成黑色横竖粗线分割的矩形，红黄蓝三原色块加白灰；左半昼、右半夜（夜半边色调反转或压暗）；燕子是黑色几何折线。记忆点：第一道闪电是一根黑色斜粗线劈过只有横竖线的网格（蒙德里安只用横竖线，这是个画史笑点）。禁区：不照搬蒙德里安具体作品的分割。
- **05 清明 · 丰子恺漫画**：毛笔墨线一笔带过、粗细有变化，淡彩薄涂，大片纸白；人物脸常常不画五官；画面一角有一行毛笔题字。记忆点：娃放风筝，田鼠一蹦变成鹌鹑，雨后出一道淡虹。禁区：不照搬他的具体名作（如「人散后，一钩新月天如水」）。
- **06 谷雨 · 苏绣**：浅色缎面底（能看见经纬），丝线按方向排针（长短针），有丝光；景物都是「绣」出来的。记忆点：浮萍一针一针绣满池塘；戴胜扇开冠羽落在桑树上（在院门旁加一棵小桑树，是允许的新增）。禁区：不绣双面绣名作里的猫、金鱼。

夏队（team-summer）：07 到 11。
- **07 立夏 · 马蒂斯剪纸**：水粉刷过的纸剪出来的大块平面形状，剪刀边缘，饱和的群青、柠檬黄、珊瑚红、绿；一切都简化成剪纸形。记忆点：剪纸蚯蚓从地里扭出来，王瓜一个接一个变红。禁区：不用他标志性的海藻形、伊卡洛斯、蓝色裸女。
- **08 小满 · 勃鲁盖尔式农民画**：北方文艺复兴的土色调（赭、橄榄绿、熟褐），田里有很多小小的农人在劳作（镰刀、麦捆），细节密。记忆点：一阵风推过，麦田从青到金一浪接一浪，娃和牛站在麦浪里。禁区：不照搬「收割者」的构图（梨树下吃午饭的那一群）。
- **09 芒种 · 齐白石草虫**：生宣纸底，大笔写意的墨叶和枝（浓淡干湿），配极精细的工笔小虫；红色印章、一行题款。记忆点：枝上的螳螂卵鞘裂开，上百只小螳螂涌出来；伯劳在枝头张嘴叫。禁区：不画虾、蟹（他的招牌题材）。
- **10 夏至 · 霍克尼式**：高饱和平涂（亮蓝、翠绿、紫、橙），池面画成他那种扭动的浅色光纹，田和树用鲜艳的色块和点；阳光最盛。记忆点：一头鹿走到田边，鹿角「咔」一声掉下来；满树蝉鸣（可用波纹或文字表现声音）。禁区：不画泳池、跳台、水花、洛杉矶房子、池边人物。
- **11 小暑 · 热成像**：整个场景按温度渲染成伪彩（铁红色板：黑、紫、红、橙、黄、白），加热像仪的界面（色标、十字准星、温度读数）。记忆点：热风成团滚过村口；院墙上的蟋蟀是一颗颗亮点；鹰俯冲拖出一道热痕。节气名用界面字体写。

秋队（team-autumn）：13 到 18。
- **13 立秋 · 霍珀式**：强烈的斜阳、长影子，干净的几何明暗块，偏暖的赭黄和压暗的绿，空寂。记忆点：娃坐在院门门槛上，第一阵凉风吹过，槐树上先黄了一片叶子。禁区：不画餐馆、加油站、灯塔、城市窗户。
- **14 处暑 · 中世纪时祷书月令页**：整页版式：上方半圆弧框里是群青天空和金色星点，太阳在一个 24 格的节气圆环上走到黄经 150°（代替原书的黄道十二宫）；下方是插图（群青渐变天空、细密的人物和田地），四周金箔加藤蔓边饰，节气名写成泥金首字母式的大字。记忆点：田里收谷子（禾乃登），鹰把捉到的鸟排成一排。禁区：不画宗教人物、黄道十二宫图形、法国城堡。
- **15 白露 · 林风眠式**：浓重的墨线和水粉色块，弯折的芦苇，剪影式的飞鸟，戏剧性的天色（橙、蓝），形体简化。记忆点：大雁排成人字飞来，燕子反方向飞走，两队在天上交错。禁区：不照搬他的仕女和「秋鹜」具体构图。
- **16 秋分 · Charley Harper 式几何**：极简几何平面，限定色板，动物用几何形组成；生态剖面图的版式。记忆点：地面剖开，地下的小虫用泥封自己的洞门（蛰虫坯户）；闪电缩回几何的云里；池水退下一圈。框内字用中世纪现代风的无衬线体。
- **17 寒露 · 镶嵌变形（埃舍尔式）**：单色石版（秋天用棕褐、赭色），密铺图形逐格变形。记忆点：天上的麻雀密铺，越过水线时一格一格变成蛤蜊的密铺；菊花一点黄色。禁区：不用他的具体图案（蜥蜴、鱼鸟互变的「天与水」），麻雀和蛤蜊的瓦片形状自己设计。
- **18 霜降 · 多层剪纸加雾（诺尔施泰因式）**：多层剪纸叠在一起，层与层之间有雾（半透明白），色调柔和的赭黄灰。记忆点：一夜霜后，老槐树的叶子在雾里一层层落光；豺把猎物摆成一排。禁区：不画刺猬、雾中白马、猫头鹰。

冬队（team-winter）：20 到 24。
- **20 小雪 · 马王堆帛画式**：褐色绢底，朱砂、墨黑、赭石、石绿，云气纹涡卷；把画面分成天、人、地三层横带。记忆点：天上的气往上飘、地下的气往下沉，中间的村子合拢入冬；一道虹折起来收走（汉代画像里虹常画成双头龙形的拱，可以用）。禁区：不画帛画里的神祇、墓主、金乌蟾蜍。
- **21 大雪 · 帕列赫漆画**：漆黑底，极细的金线排线提亮，宝石般的蛋彩色，修长的形体，金色装饰边框；白雪。记忆点：两只金线老虎在雪地里绕圈相蹭（只画亲昵，不往下画）；寒号鸟在枝上闭嘴；马蔺叶子从雪里挺出来。禁区：不画俄罗斯童话人物、三驾马车、火鸟、洋葱顶。
- **22 冬至 · X 光透视**：蓝黑底片，结构发光；冻土透明，能看到地下。记忆点：地下打着结的蚯蚓，一股暖泉开始流动，这股暖色是全画面唯一的暖色（一阳生）；麋鹿掉角时角是透视的骨质。牛可以显出骨架；娃只显柔和的轮廓发光，不画骷髅。
- **23 小寒 · 民国月份牌**：擦笔水彩（柔和的炭粉擦底加透明水彩，平滑渐变、粉彩），华丽的月历边框和民国美术字，边框里有新一年的月份格。记忆点：喜鹊在光秃的槐树上一根根搭窝。禁区：不画月份牌常见的时装美女和香烟、商品广告。
- **24 大寒 · 冰梅纹**：白底蓝纹或木窗棂色，冰裂纹（不规则多边形网格）上缀白梅。记忆点：池冰一路冻透，裂纹长满整个画面，变成冰梅纹窗棂；窗棂后面母鸡孵出小鸡；一只隼疾飞而过。循环收尾：4 秒处冰纹淡成靛蓝和纸白（呼应立春的型染）。
