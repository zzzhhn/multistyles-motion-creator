# 02 · 选题和单元总表（BIBLE）

总表是全片的唯一事实来源：每个单元一行，引擎从它生成时间线，各队从它领任务，配乐从它读配器。示例见 `assets/example-xiyou-81nan/BIBLE-v09.md`（v09 时的表，时长后来改了）和 `src/cells.js`（引擎读的数据）；第二个示例的表在 `assets/example-jieqi-24/artlock/terms.js`。

## 选题（用户要「再做一部」时）

《二十四节气》是从这几条筛出来的，下次照用：

1. 一份观众熟悉、自带编号的清单（八十一难、二十四节气、三十六计、山海经），编号就是贯穿全片的计数器。
2. 每个单元有一个一眼认得出的具体事件（节气的三候：鹰化为鸠、腐草为萤、雉入大水为蜃），记忆点现成。
3. 有一个能贯穿全片的主体，并且它会变化（师徒四人；农妇、娃、耕牛和一头会长大的小牛）。
4. 原作是公有领域。
5. 配乐能有自己的曲式（节气按四季分四段，八十一难按九行分九段）。

同时定骨架（`01-research.md` 的四种骨架）：有路线的用「画廊墙横移」，同一个地方随时间变化的用「同一处过一年」（固定构图，换画风；节气就是这种）。

## 每行的字段

| 字段 | 说明 |
|---|---|
| n | 编号，从 1 开始 |
| name | 单元名目（原作里的名称，逐字核对） |
| style | 画风键名（英文小写，也是 `src/styles/<style>.js` 的文件名） |
| sub | 展签副标题：画风名 · 年代 · 地区 |
| beats | 拍数（时长）；示例里普通单元 8 拍、关键单元 12 拍 |
| size | 画框宽度档（与时长分开，改时长不必改构图） |
| scene | 种子画面：这一段的具体情节、谁在、什么法宝、什么地形。各队可以改得更贴原作 |
| text | 框内字（2 到 6 个字），按本画风的书写方式写 |
| inst | 时代代表乐器（配乐只在「每行一种独奏」的粒度上用它，见 06） |
| story | 主体在这个单元做什么、身上有什么变化（衣服、道具、成长），上一单元结尾的动作怎么接进来。写成故事轨数据，见 `10-story.md` |
| trans | 进入这个单元的过渡由什么现象带进来（雨幕、惊雷、霜、冰、落雪……），见 `10-story.md` 第五节 |

模板见 `templates/bible-row.md`。**故事和过渡这两栏在写总表时就要写，不要等成片后补**：《二十四节气》v1 只有单元没有故事，被用户评「故事感不强」，v2 重做了一整天（`11-error-analysis.md` S4）。

## 原作核对（必须做）

- 找到原作里列出这些单元的原文（《八十一难》是第九十九回的难簿，维基文库可取 raw 文本），逐条转写，存进 `refs/`。
- 记下原作和通行说法不一致的地方。例：难簿上只有 80 条，第 81 难是观音临时「补」的一难（老鼋落水、晒经），原文没有给它起名，表里要标「名目自拟」。
- 角色在场情况按原作排一张表（谁从第几个单元加入、在哪几个单元缺席），后面写进引擎的 `castAt`，见 03。

## 画风选择和排序

- **先定画风和主题的文化关联要多紧**，这条会改变整张表：
  - 《八十一难》用户明确说「不局限于某个地区，各种画风都可以用」，所以按艺术史从岩画排到当代。
  - 《二十四节气》第一版照搬了这个口径，用了型染、新版画、风格派、霍珀等，用户看图后说「有几个日式风格的虽然看着不错，但是本质上和主题的关联性有点弱了」，换成 21 种中国画风（蓝印花布、景泰蓝、界画、蔚县剪纸、户县农民画、青绿山水、李可染、耕织图、科普挂图、七巧板、马夏、北大荒版画、描金漆画……）。
  - 默认：主题有明确文化归属时，先用这个文化自己的画风（传统和现代都算）；外来画风或现代媒介只在服务内容时用（热成像拍「温风至」、长曝光拍「腐草为萤」、X 光拍冬至地下的「水泉动」）。拿不准就在 Art Lock 前问一句。
  - 同一文化内要靠材质拉开距离，否则几种水墨、几种工笔在 1 到 2 秒里分不出来：节气的 21 种中国画风里水墨类只有 6 种（点线、漫画、写意花鸟、彩墨、积墨、南宋水墨），中间隔着蓝印花布、景泰蓝、苏绣、剪纸、漆画、瓷纹、木刻等不同材质。
- 一单元一种画风，全片不重复。可以按时间顺序排（从岩画到当代），观众会有「穿越艺术史」的顺序感；也可以按单元的气质排（节气按季节：春清新、夏饱和、秋金褐、冬冷而少色）。
- 关键单元配最有分量的画风：开场第一格要能「画自己画出来」；主角加入、被逐出、真假之辨、最终升华这类转折点放在辨识度最高的风格上，并给更长的时长。
- 版权：学画风语言，不画受版权保护的具体角色设计（例：1961 年《大闹天宫》的孙悟空、1986 年电视剧剧照、《黑神话：悟空》的角色；吉卜力、新海诚、Kirby、韩漫只学视觉语言）。原作是公版的可以随便用。

## 画风分族（降低实现成本）

把画风按「媒介」分族，族内共用一套渲染思路，用参数区分：

1. 刻痕线：岩画、画像石、木刻版画、连环画
2. 平涂勾线：埃及、拜占庭、年画、海报、扁平插画
3. 砖与点：马赛克、点彩、像素、信息图
4. 笔触：印象派、后印象、表现主义、野兽派、水墨、水彩
5. 材质：青铜、青花、彩陶、彩色玻璃、泥金、金箔、剪纸、皮影、纸偶、沙画、拼贴
6. 胶片与摄影：蓝晒、默片、黑色电影、录像带、动画电影光影
7. 三维：线框、低多边形、等距
8. 平面构成：包豪斯、构成主义、瑞士风格、装饰艺术、波普、欧普
9. 文字与图形：甲骨、楔形文字、星图、字符画

风险最高、最该先做原型的是：文字体系（甲骨、楔形）、关节剪影（皮影）、字符画、墨晕、光晕与赛璐珞阴影。

## 时间网格

- 用 BPM 定一切时间：单元从小节线开始，时长是整拍数。示例 v10 起用 90 BPM，一拍 0.667 秒，普通单元 8 拍（2 小节，5.33 秒），关键单元 12 拍（3 小节，8 秒）；开场 12 拍，片尾 16 拍；81 个单元全片 466.67 秒。
- 画框宽度和时长分开：`size` 定宽度，`beats` 定时间，镜头在格内放慢、过缝加快（`core.js` 的 `EASE_A`）。
- 时长定下后报给用户全片长度。v09 的 2.5 秒格全片 3 分 42 秒，改 5.33 秒后变成 7 分 47 秒，这是用户主动要的。
