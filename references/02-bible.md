# 02 · 单元总表（BIBLE）

总表是全片的唯一事实来源：每个单元一行，引擎从它生成时间线，各队从它领任务，配乐从它读配器。示例见 `assets/example-xiyou-81nan/BIBLE-v09.md`（v09 时的表，时长后来改了）和 `src/cells.js`（引擎读的数据）。

## 每行的字段

| 字段 | 说明 |
|---|---|
| n | 编号，从 1 开始 |
| name | 单元名目（原作里的名称，逐字核对） |
| style | 画风键名（英文小写，也是 `src/styles/<style>.js` 的文件名） |
| sub | 展签副标题：画风名 · 年代 · 地区 |
| beats | 拍数（时长）；示例里普通单元 8 拍、关键单元 12 拍 |
| size | 画框宽度档（与时长分开，改时长不必改构图） |
| scene | 种子画面：这一段的具体情节、谁在、什么法宝、什么地形。各队可以改得更贴原作 |
| text | 框内字（2 到 6 个字），按本画风的书写方式写 |
| inst | 时代代表乐器（配乐只在「每行一种独奏」的粒度上用它，见 06） |

模板见 `templates/bible-row.md`。

## 原作核对（必须做）

- 找到原作里列出这些单元的原文（《八十一难》是第九十九回的难簿，维基文库可取 raw 文本），逐条转写，存进 `refs/`。
- 记下原作和通行说法不一致的地方。例：难簿上只有 80 条，第 81 难是观音临时「补」的一难（老鼋落水、晒经），原文没有给它起名，表里要标「名目自拟」。
- 角色在场情况按原作排一张表（谁从第几个单元加入、在哪几个单元缺席），后面写进引擎的 `castAt`，见 03。

## 画风选择和排序

- 一单元一种画风，全片不重复。按时间顺序排（从岩画到当代），观众会有「穿越艺术史」的顺序感，结尾自然落到当代媒介。
- 不必局限于原作所在地区的画风（用户明确说过各种画风都可以用）；但纯本土画风凑数时会出现很多近邻风格（几种水墨、几种工笔），1 到 2 秒里分不出来。
- 关键单元配最有分量的画风：开场第一格要能「画自己画出来」；主角加入、被逐出、真假之辨、最终升华这类转折点放在辨识度最高的风格上，并给更长的时长。
- 版权：学画风语言，不画受版权保护的具体角色设计（例：1961 年《大闹天宫》的孙悟空、1986 年电视剧剧照、《黑神话：悟空》的角色；吉卜力、新海诚、Kirby、韩漫只学视觉语言）。原作是公版的可以随便用。

## 画风分族（降低实现成本）

把画风按「媒介」分族，族内共用一套渲染思路，用参数区分：

1. 刻痕线：岩画、画像石、木刻版画、连环画
2. 平涂勾线：埃及、拜占庭、年画、海报、扁平插画
3. 砖与点：马赛克、点彩、像素、信息图
4. 笔触：印象派、后印象、表现主义、野兽派、水墨、水彩
5. 材质：青铜、青花、彩陶、彩色玻璃、泥金、金箔、剪纸、皮影、纸偶、沙画、拼贴
6. 胶片与摄影：蓝晒、默片、黑色电影、录像带、动画电影光影
7. 三维：线框、低多边形、等距
8. 平面构成：包豪斯、构成主义、瑞士风格、装饰艺术、波普、欧普
9. 文字与图形：甲骨、楔形文字、星图、字符画

风险最高、最该先做原型的是：文字体系（甲骨、楔形）、关节剪影（皮影）、字符画、墨晕、光晕与赛璐珞阴影。

## 时间网格

- 用 BPM 定一切时间：单元从小节线开始，时长是整拍数。示例 v10 起用 90 BPM，一拍 0.667 秒，普通单元 8 拍（2 小节，5.33 秒），关键单元 12 拍（3 小节，8 秒）；开场 12 拍，片尾 16 拍；81 个单元全片 466.67 秒。
- 画框宽度和时长分开：`size` 定宽度，`beats` 定时间，镜头在格内放慢、过缝加快（`core.js` 的 `EASE_A`）。
- 时长定下后报给用户全片长度。v09 的 2.5 秒格全片 3 分 42 秒，改 5.33 秒后变成 7 分 47 秒，这是用户主动要的。
