# 10 · 故事轨：让换画风的长片有故事感

来源：《二十四节气》v1 被用户评「画面故事感不强……不同节气之间的连接，无论是画面自然切换还是说主体（农妇、耕牛）的变化都没做好」，v2 用本文的做法重做后用户评「这轮做的视频的质量又更好了」。可运行实现在 `assets/example-jieqi-24/artlock/`（`story.js story2.js storydata.js storydata2.js figures2.js figures3.js trans.js titles.js`）。

## 一、核心想法

**主体的状态是全片时间的函数，由引擎统一计算；画风只负责「怎么画」。**

- 主体（人、动物、道具）在某一时刻的位置、朝向、动作、衣服、手里的东西、长到多大，只由全片时间决定，和当前是哪种画风无关。
- 换画风时，主体原地不动、动作连续，只有世界换了画法。观众会把注意力放在主体身上，画风的变化反而成了「时间在走」的证据。
- 衣服按季节换、小牛犊从清明出生到大寒长大、农具随农事变化：这些变化就是「主体的变化」，用户要的故事感主要来自这里。
- v1 的做法是每种画风在固定位置自己画娃和牛：位置、姿势、大小各不相同，换画风时人物会跳，也看不出一年里发生了什么。

## 二、数据结构（示例在 `storydata.js`）

```js
JQ.STORY_KEYS = {
  3: { woman: [[0, 1080, 632, 'walk', 0], [1.6, 1210, 636, 'plow', -1], [8, 770, 646, 'plow', -1]],
       kid:   [[0, 1420, 668, 'walk', 0], [2.2, 1290, 652, 'squat', -1], ...],
       ox:    [...] },
  ...
};
// 每个关键帧：[单元内时间 0..8 秒, x, y, 姿势, 朝向（0 = 朝走的方向）, 可选 { a: 透明度 }]
JQ.STORY_PROPS = { 3: [['plow', 'woman', 1.6, 9]], ... };   // 道具：种类、在谁身上、起止时间
```

- 姿势在关键帧之间保持，在下一个关键帧之前 0.3 秒混合到下一个姿势；卧和站之间用 0.6 秒的起身或卧下过渡。
- 走路的相位按走过的距离算（步子不会打滑），干活的动作（锄、割、打连枷）按拍子算，和配乐同步。
- 远近缩放由地面高度决定（`JQ.STORY_S(y)`），田里远处的人约 0.7 倍。
- 衣服由「画风所属的单元」决定，所以换装恰好发生在新画风长出来的地方。
- 小牛的成长参数从出生那个单元开始按全片时间线性增长到 1。

## 三、画风怎么用

- 每帧调用 `const C = JQ.castFor(Sx, t)`。`C.items` 已经按远近排好，每项 `{ who, kind, parts, y, alpha }`；`parts` 是 `[{ role, pts, path }]`（点列和 Path2D），`parts.joints` 给出手、头、肩、髋的位置，供道具和事件对位（例如立春的冰片飞进娃举起的手）。
- `Sx.lt` 是引擎传的真实单元时间（过渡时进来的画风是负数，出去的画风大于 8）。用它取人物，两种画风在接缝两边画的是同一时刻、同一位置的人。
- 按 role 用本画风的笔法画：刻线、针脚、剪纸刀口、墨色晕染、热像亮度、X 光骨架、七巧板块。最省事的是 `JQ.drawCastFor(g, Sx, t, pen)`。新 role（围裙、头巾、草帽、蓑衣、小牛、木、铁、草、红）在 pen 里没写时会回退到已有 role 的颜色。
- 画风不改人物的位置和动作。觉得故事和画面冲突，写进交接，由主线改故事数据。

## 四、检查和预览

- `node tools/storycheck.cjs`：每个单元结尾和下一单元开头，每个主体的位置（误差不超过 2 像素）、朝向、卧还是站必须一致（含循环版的 24 接 1）；关键帧不能出画面；不能「不走路却在移动」（滑步）；道具种类必须是运行时认识的。
- `node tools/castsheet.cjs 1-24`：在中性的平涂底图上画出一家人，每单元 5 个时刻，一眼看出位置、远近、遮挡和故事是否讲得通。
- 各画风队在交接里写「单元·人物·秒数·问题」，这一轮发现的典型问题：人物从院墙墙面上走过去、两个主体重叠、人站在牛头后面、道具在单元交界处消失、出生的小牛和跪着的农妇隔着一头牛。都要改故事数据，不要让画风去绕。

## 五、和故事轨配套的三件事

1. **现象过渡**（`trans.js`）：下一单元的画风由它自己的自然现象带进来：雨幕斜扫、惊雷撕开、昼夜从中线分开、夏风横推、夜幕从上落下、露珠或雪片一格格打开、霜从四角蔓延、冰片从池塘铺开、热浪圈、阳光从太阳处扩散。窗口是边界前 0.45 秒到边界后 0.85 秒；最后 20 % 统一交叉淡化，避免收尾整屏一跳。
2. **统一标题卡**（`titles.js`）：每个单元开头，引擎在天空展开一条自带纸底的题签（名字、序号、日期、三个子事件、季节印），任何画风上都清楚；单元简报里预留这块区域；和画风自带文字冲突时按单元调位置。
3. **地面状态对上故事**：犁过的地方留犁沟，割过的地方留麦茬和麦捆，扫过的地方变干净，场院铺谷子。这些由画风画，但要跟着人物的位置走（取 `C.state` 里农妇的 x）。

## 六、怎么写一年（或一段旅程）的故事

- 先列「主体在每个单元做什么」的一行表（节气版见 `assets/example-jieqi-24/STORY_BRIEF.md` 的地面状态表），一单元一件事，事件之间要能接上：上一单元结尾的动作，是下一单元开头的动作。
- 加一条随时间成长的线（小牛犊、一棵树、一座房子），观众靠它感到时间在走。
- 结尾要能接回开头（循环版）：大寒长大的小牛走进院门，立春一家人又在院门口给牛系红绸。
- 写完先跑 `storycheck`，再出 `castsheet` 看一遍，最后才派画风队去画。
